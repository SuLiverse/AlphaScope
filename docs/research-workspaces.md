# 可恢复研究工作区

入口：研究报告生成页顶部的“研究工作区”。此功能不需要额外模型调用；生成或重试研究时仍使用现有分析流程。

## 工作流程

1. 选择股票，填写研究问题和数据截止日。资料可附标题、原文链接、发布日期和原文摘录。
2. 保存草稿，或直接生成报告。生成前自动保存草稿，每次运行分配独立的版本号。
3. 重新进入报告页会继续最近的工作区。也可从列表选择其他研究或指定版本。
4. 沿用问题、修改截止日后再次生成，可得到新版本。旧版本的输入、行情、证据与模型结果不会被覆盖。
5. 点击“复核”视图中的论断，核对原文摘录、来源及日期，标记支持、部分支持、不支持或待补充，并填写理由。
6. 可以标注支持/反对证据并填写修订结论。修订显示在复核列表，原始模型输出保留。每次复核追加一条记录。
7. “差异”视图可选择同一工作区的更早版本，比较研究条件、证据、指标、Agent 观点和模型配置。

## 报告视图

- 报告分为概览、全文、复核、差异、资料五个视图；完成或恢复报告后自动收起研究参数，可随时重新展开。
- 标题、研究问题与截止日来自当前报告的冻结输入和结果，编辑下一版草稿不会改变当前报告的身份。
- 复核支持全部、未复核、存在反证筛选，以及保存并下一条。桌面并排查看列表与详情，手机以全屏详情复核。
- 切换报告标签保留当前复核草稿。切换论断、工作区、版本或重新研究时，未保存的修改需要确认放弃；浏览器关闭或刷新也有离开提示。未保存复核不会写入持久化存储，离开整个报告模块不保留草稿。
- 差异优先展示结论与变化数量，证据可展开查看原文摘录，模型配置默认折叠，无差异分组默认隐藏。
- 数据采集状态、证据来源/日期覆盖率、人工复核进度分别显示。无采集记录不视为健康，已保存复核包含待补充等状态，不等于论断获支持。

## 数据边界

- SQLite 表：`research_workspaces`、`research_versions`、`research_claim_reviews`，使用现有 `Database` 路径。
- 版本结果独立于任务队列表保存，任务清理不会删除研究版本。任务 Markdown 导出仍使用原有任务导出接口。
- 证据摘录保存检索到的原始片段（最多 12,000 字符），不声称保存了整份公告或 PDF。原文链接仍指向来源。
- 引用只表示关联，不自动等于“支持”。Agent 级引用与论断中的明确引用分别标记；支持/反对关系由复核者确认。
- 历史截止模式排除日期缺失或晚于截止日的补充资料；这类资料仍保留在草稿与输入快照中。
- 已保存研究的图表使用版本中的价格/技术指标快照，不重新拉取当前价格、因子或形态填充旧报告。未存档的图表数据保持缺失。
- 比较只报告记录的变化，不推断因果。没有结构化财务指标或模型配置的版本会明确警告，不能将缺失解释为“不变”。
- 模型配置保存请求覆盖与已解析配置，并记录实际返回模型及 fallback 状态。凭据、请求头和临时端点不会进入配置存档。
- 含临时凭据或端点覆盖的运行不允许静默省略这些参数后重试，需使用当前配置生成新版本。
- 历史 Markdown 存档没有被自动解析或伪造为结构化快照；旧任务结果仍可用原入口查看。

## 恢复粒度

第一版提供两个持久化阶段：行情采集、研究分析。分析阶段异常后重试可复用已完成的行情快照，但会重新执行证据检索与研究分析，不是单个 Agent 的断点续跑。重试产生新版本并保留原失败版本及关联。

后台进程重启后，旧的运行中任务标记为中断，允许显式重试。浏览器刷新不会重复提交任务，而是继续查询原任务。一个工作区同时只允许一个运行。此队列仍沿用项目原有单进程运行约束，不适用于多 worker 共享执行器。

## API

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET / POST | `/api/research-workspaces` | 列表 / 保存新草稿 |
| GET / PUT | `/api/research-workspaces/{id}` | 读取 / 修改草稿 |
| GET | `/api/research-workspaces/versions/{id}` | 冻结版本、论断、复核历史 |
| PUT | `/api/research-workspaces/versions/{id}/claims/{claim_id}` | 追加复核记录 |
| GET | `/api/research-workspaces/{id}/compare?before=...&after=...` | 比较同一工作区的已完成版本 |
| POST | `/api/analysis/async` | 原接口新增 `workspace_id`、`materials`、`retry_from` |

复核写入要求 `expected_revision`，旧修订号返回 409，避免多个窗口覆盖。陌生论断、跨版本证据、跨工作区比较或未完成版本不允许写入/对比。接口继承现有本地 API 鉴权。
