# v1.9.x 界面截图与演示素材

## 当前素材

以下文件由本地 Vite + Playwright 以 1920×1200 视口生成：

| 文件名 | 内容 | 建议尺寸 |

| `workbench.png` | 股票工作台主界面（K 线 + 新闻 + 公告 + 指标卡片） | 1920×1200 |
| `report-generator.png` | 研究报告生成页（研报参数 + 生成入口 + 空状态） | 1920×1200 |

| `golden-path.gif` | 由上述 4 张截图合成的轻量黄金路径动图 | 960×600，≤ 5MB |

## 重新生成建议

- 用 **Demo 零 Key 模式**启动，避免截图暴露个人 API Key。
- 截图统一暗色主题，视口保持 1920×1200。
- 如需真实 60 秒操作录屏，可用 [ScreenToGif](https://www.screentogif.com/) 或 OBS 录制「搜股 → 工作台 → 研报 → 证据链 → 回测 → 导出」，再覆盖 `golden-path.gif`。

## 复核

更新素材后请确认：

1. `README.md` 不再引用 `docs/assets/v1.4.1/` 作为首屏预览。
2. `golden-path.gif` 小于 5MB。
3. 四张 PNG 不是加载中、空白页或被引导弹窗遮挡。
