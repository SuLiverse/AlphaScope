# 文档索引

产品功能以代码与主 `README.md` 为准；本目录只做**文档归位**，不删功能说明内容。

| 路径 | 内容 |
|------|------|
| `architecture.md` / `api.md` / `user-manual/` 等 | 现行架构与手册 |
| `evaluation.md` / `reproducible-research.md` | 研究可信度评分、基线比较与历史截止快照 |
| `releases/` | 各版本 `RELEASE-NOTES-*.md`（从仓库根目录迁入） |
| `archive-notes/` | 历史交接、前端适配审计、`AUDIT-2026-07-01` 等 |
| `assets/` | README 截图与 GIF |

变更日志仍在仓库根目录：`CHANGELOG.md`。
